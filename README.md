## The joke

> I renamed my home Wi-Fi 'Meeting in Progress' so my coworkers would stop calling — it worked so well my boss promoted the router.

## How it works

`main.ts` (Node 22) writes the joke to `/output/entry.txt`. The entry is a single line, well under the 200-character gate, built on a true office observation — endless meetings and coworkers always calling — with a surprising last word: the router gets promoted.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`.
